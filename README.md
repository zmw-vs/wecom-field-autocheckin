# 企微外勤自动打卡（wecom-field-autocheckin）

个人自用的企业微信考勤辅助工具。到点自动拉起企业微信，点开工作台的打卡应用并点击「上班打卡 / 下班打卡」，省掉每天手动找入口的那几步。

主要针对外勤人员设计，避免忘记打卡，它能在固定时间自动拉起企业微信，重复人工打卡的步骤。

**它不是打卡作弊工具**：定位用的是手机实时定位，不虚拟、不篡改；打卡记录是企业微信真实产生的。它做的只是"替你把那几个按钮点一下，需要赋予无障碍权限，可放心使用，工具本身不会做任何数据收集和上传。仅通过接口获取节假日这一个联网动作。其余动作均不联网"。

---

## 功能

- **定时自动打卡**：上班、下班两个时间点独立配置，到点自动执行
- **两级触发**：闹钟到点后直接拉起企微执行；若当时锁屏，则等到解锁后补执行
- **工作日判定**：星期几掩码 + 法定节假日（自动跳过）+ 调休补班日（照常打卡）
- **自定义不打卡日**：年假、调休、公司额外放假，按年份管理，指定当天不打卡
- **手动补打**：「立即打卡」按钮随时手动触发一次真实打卡
- **演练模式**：长按「立即打卡」只走界面流程、不写任何状态，可反复测试
- **状态防重**：上班卡、下班卡分别记录当日是否已打，避免重复
- **省电设计**：非唤醒闹钟、事件面裁剪、无常驻轮询、无前台服务

## 工作原理

```
AlarmManager(RTC, 非唤醒)
      │  到点（若休眠则顺延到下次唤醒）
      ▼
AlarmReceiver ──► 二次校验今日是否工作日
      │
      ▼
无障碍服务启动企业微信
      │
      ▼
工作台 → 找「打卡」入口（首屏没有则翻页查找）
      │
      ├─ 直达打卡应用 ─────────────┐
      │                            ▼
      └─ 预览页 → 右上角「…」→「进入应用」
                                   │
                                   ▼
                        点击「上班打卡 / 下班打卡」
                                   │
                                   ▼
                     外勤弹窗 → 点「确认打卡」
                                   │
                                   ▼
                     等待结果；需拍照/定位时通知本人
```

## 环境要求

| 项                     | 版本                                  |
| --------------------- | ----------------------------------- |
| JDK                   | 17                                  |
| Android SDK           | compileSdk / targetSdk 34，minSdk 29 |
| Gradle                | 8.9（wrapper 自带）                     |
| Android Gradle Plugin | 8.6.1                               |
| Kotlin                | 2.0.20                              |

运行时要求 Android 10（API 29）及以上。**不需要 root**，只依赖系统的无障碍服务。

## 构建

### 方式一：Android Studio

直接 `Open` 本目录，等 Gradle 同步完成后运行 `app` 即可。

### 方式二：命令行

```bash
# Linux / macOS
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew assembleDebug
```

```bat
:: Windows
gradlew.bat assembleDebug
```

产物路径：`app/build/outputs/apk/debug/app-debug.apk`

Windows 上也可以双击 `build-apk.bat`，但**需要先把里面的 `JAVA_HOME` / `ANDROID_HOME` 改成你自己的路径**

### 安装

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 关于镜像

工程默认走国内镜像加速，海外环境构建时可能需要调整：

- Gradle 分发包：`gradle/wrapper/gradle-wrapper.properties` 指向腾讯云镜像
- 依赖仓库：`settings.gradle.kts` 里阿里云优先，`google()` / `mavenCentral()` 作兜底

工程名 `AutoCheckIn`，应用显示名为「外勤打卡助手」，包名 `com.zmw.autocheckin`。

## 首次使用

1. 打开 App，至少手动启动一次（Android 13+ 未启动过的应用收不到开机广播）
2. 点「权限检查」，逐项开启：
   - **无障碍服务** —— 必开，否则无法点击按钮
   - **通知权限** —— 打卡失败时靠它提醒你
   - **精确闹钟** —— Android 12+ 必须允许，否则定时不准
   - **电池优化** —— 设为「不受限制」
   - **自启动（三星）** —— 电池 → 后台控制 → 自动运行应用 → 打开本应用
3. 点「自动打卡设置」，配好上下班时间、生效星期、节假日规则
4. 先长按「立即打卡」跑一次演练，确认界面链路能走通，再正式用

## 已知限制

- **企业微信打卡页是 H5 渲染的**，无障碍节点树里能读到的信息很少。工作台里能稳定命中「打卡」文本，但进入打卡应用后，页面元素的可识别程度取决于企微版本。基于5.0.13制作，可以点到「上班打卡 / 下班打卡」和「确认打卡」文字，换版本可能需要调整匹配对应的文字。
- **外勤打卡需要本人确认时，自动化会停**。点了「确认打卡」之后，如果企微要求拍照或实时定位确认，工具会等待几秒结果，等不到就发通知让你手动完成——这类涉及本人操作的步骤，本工具不会代劳。
- **锁屏时不唤醒屏幕**。这是省电换来的代价：锁屏状态下流程会空转直到超时，靠解锁后补执行。
- **节假日数据**默认取 `https://timor.tech/api/holiday/year`，属于第三方公共服务，可能限流或失效。内置了 2026 / 2027 的法定节假日表，也可以在设置里换成自己的接口地址（支持 `{year}` 占位符）。

## 目录结构

```
app/src/main/
├── AndroidManifest.xml
├── java/com/zmw/autocheckin/
│   ├── CheckInAccessibilityService.kt   无障碍服务：打卡链路状态机
│   ├── CheckInScheduler.kt              闹钟排期（非唤醒 RTC）
│   ├── Receivers.kt                     闹钟/开机广播、时段归属判定
│   ├── HolidayApi.kt                    节假日接口请求与多格式解析
│   ├── HolidayRepo.kt                   节假日数据源选择与逐日展开
│   ├── WorkDay.kt                       今天算不算工作日
│   ├── Prefs.kt                         配置与每日状态持久化
│   ├── Notifier.kt                      通知渠道与提醒
│   └── MainActivity.kt                  纯代码 UI
└── res/
    ├── values/                          应用名、无障碍服务说明
    └── xml/accessibility_service_config.xml
```
